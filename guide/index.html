基础入门 新手必看必学

1. 官方及第三方一键中文汉化

Telegram 官方隐藏了中文选项，且机翻感较重。我们强烈推荐使用开源社区公认最权威的“聪聪简体中文包”，翻译精准、更新极快。无需繁琐设置，点击下方按钮即可一键唤醒 Telegram 并安装：

🇨🇳 点击一键安装「简体中文包」

* 若需繁体或语言包失效，请联系 @zhplayers 获取最新备用链接。

2. 解除无法主动发起私聊（双向限制）

使用 +86 等部分地区手机号注册的用户，默认会被 Telegram 官方实施“防范性限制”，导致你无法主动给非双向联系人发送私聊消息。你可以通过向官方机器人申诉免费解除：

  1. 点击下方按钮向官方 @SpamBot 发送消息：/start
  2. 点击选项：But I can't message non-contacts!
  3. 点击选项：No I'll never do any of this!
  4. 输入单词：accident 并发送。

等待 30 分钟到几小时不等即可自动解除。Bot 不会通知你，请自行找人私聊测试。

🤖 前往 @SpamBot 申诉解封

3. 收不到短信验证码的玄学与对策

这是全网最让人头疼的问题，Telegram 的验证码发送逻辑非常“玄学”，请熟知以下核心规则：

  • 首次注册必须使用官方手机客户端，电脑端无法直接注册。
  • 老号登录时，验证码会优先发送到你已经登录的其他设备（客户端）上，而不是发短信。
  • 如果确认没发到其他设备，也没有被运营商拦截，建议尝试使用网页版登录开通“通行密钥 (Passkey)”，彻底告别验证码烦恼。

账号安全 防封防盗必设

1. 最高警戒：强烈建议立即开启“两步验证”

仅仅依靠短信验证码极度危险！一旦验证码被拦截或设备被木马劫持，你的账号将瞬间易主。开启两步验证（Two-Step Verification）后，即使别人拿到你的短信验证码，没有你设置的密码也绝无可能登入。

操作路径：设置 → 隐私和安全 → 两步验证 → 开启。

⚠️ 警告：请务必牢记密码，并一定要设置“恢复邮箱”！如果忘记密码且未设邮箱，该账号将永久丢失无法找回。

2. 隐私设置：防止被乱拉各种广告群

为了避免一觉醒来发现自己被拉进几十个币圈或灰产群，请立即修改你的群组邀请权限：

设置 → 隐私和安全 → 邀请权限（群组与频道）→ 改为「我的联系人」

进阶玩法 效率与极客操作

1. 彻底解决 Telegram 占用大量手机空间

Telegram 会自动缓存你浏览过的所有视频和图片，动辄占用十几GB。不要傻傻地去删聊天记录，TG 的所有内容都永久存在云端，你只需要清理本地缓存即可：

  • 清理缓存：设置 → 数据与存储 → 存储使用情况 → 点击「清空缓存」。
  • 一劳永逸：在同个界面，将“保留媒体时间”从永远改为「1个月」或「1周」，并设置最大缓存上限。

2. 玩转富文本排版与“隐藏剧透”

发消息时，选中你输入的文字，长按（或右键）呼出格式菜单，你可以对文字进行 加粗、斜体、删除线 等操作。最受欢迎的是 剧透 (Spoiler) 功能，发送后的文字会被一层马赛克遮挡，对方必须点击才能看清内容，非常适合防剧透或发送敏感词。

硬核科普 知其然知其所以然

1. 圈内“黑话”词典

UID (用户ID)

你的账号底层唯一数字标识，无法更改。注销重注会生成新的。无法直接用于搜索加好友。

Ban / 踢出 / 封禁

被群管拉黑，无法再加入该群；如果是账号被官方Ban，意味着彻底封号。

Mute / 禁言

你依然在群里，也能看到聊天，但你的输入框会被冻结，无法发送任何消息。

DC (数据中心)

TG 在全球的服务器节点。中国+86号码通常在 DC5(新加坡)，美国号码通常在 DC1(迈阿密)。

2. TG 真的完全没有内容审查吗？

这是一个误区。虽然 TG 极为注重隐私，但并非法外之地：

  • 私聊极为安全：官方绝不会自动扫描或审查私聊记录，除非接收方主动举报该消息。
  • 公开群/频道受监管：对于公开（有用户名或公开发布链接）的频道和群组，系统会自动检测已知的极端主义、虐待儿童等严重非法内容。
  • 连带责任：如果群组被认定传播严重违规内容，群主及参与管理的账号可能面临永久封禁。普通成员通常免责。
