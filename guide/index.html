📱 客户端大全与无限多开

Telegram 官方代码是开源的，但也存在大量夹带私货的危险第三方App（如搜索排名前列的“Telegram中文版”，带有收费会员，极度危险）。请认准以下公认安全版本：

⬇️ 官方与安全第三方下载指南 ▼

Android/安卓：官方包 (@TAndroidAPK)，官网 (telegram.org/dl/android/apk)，Google Play商店。轻量版: Telegram X (@tgx_log)。

iOS/苹果：非国区 AppStore 搜索 Telegram。注意：Telegram、Signal 等已从中国区下架，需使用美区/港区 ID。

Windows：官网下载 (telegram.org/dl/desktop/win) 或 Github 官方发布页。

macOS：支持 macOS(Swift) 版本与 Desktop Qt 版本。

安全的第三方：iOS (Swiftgram, iMe Messenger, Nicegram)；Android (Plus Messenger)；Windows (Unigram, Kotatogram)。

👥 如何实现客户端多开？ ▼

iOS / Android：官方客户端内点击设置，可直接添加账号，同时登陆3个账号。若需更多，Android 可用系统分身/双开功能，iOS 可安装不同第三方客户端。

Windows 电脑：最简单多开法：把安装目录中的 Telegram.exe 复制一份到另外一个文件夹，即可实现 N 开！

🔐 登录、验证码与两步验证

收不到短信验证码的终极玄学

验证码由第三方代理商发送，玄学极多。核心规则：自2021年起，首次注册必须用手机端；老号登录时，验证码优先发送到已登录的客户端上，而非短信。

  • 国内 +86 和 Google Voice 确实能收到，但部分号码可能触发高昂短信费规则（甚至收费送 Premium）。
  • 邮箱登录：部分用户会触发绑定邮箱接收验证码（灰度测试中，如果提示 EMAIL_NOT_ALLOWED 请换域名）。
  • 最终解法（2025年12月更新）：登录网页版，开启“通行密钥 (Passkey)”。此后登录无需验证码，彻底摆脱短信和邮箱限制！

强烈建议：开启两步验证

为防账号被盗，必须在 设置 → 隐私和安全 → 两步验证 中开启密码，并务必绑定恢复邮箱。若忘密码且无邮箱，账号将永久报废。

💬 富文本排版、发图带字与缓存清理 ▼

富文本与剧透：选中输入的文字，呼出格式菜单，可设置 加粗、斜体、删除线、等宽代码 以及最酷的 剧透 (Spoiler)（马赛克遮挡，点击显示）。

发图带文字：在手机端，直接点击图片本身（而不是勾选右上角的圈），底部就会出现“添加说明”输入框。选“文件”格式发送可避免画质压缩。

清理缓存：TG 极其占内存，请在 设置 → 数据 → 存储使用 → 清理缓存 中操作，并把“保留时间”改短。注意：清理缓存不会删除云端聊天记录！

🕵️ eSafety 披露：TG 的内容审核与封禁规则 ▼

基于澳大利亚 eSafety 的调查披露，TG 并非法外之地：

  • 私聊审核：极其严格保护。系统不扫描私聊，仅当接收方主动举报时，消息才会转给人工审核。
  • 公开群/频道：系统会自动扫描照片和视频，以检测已知的极端恐怖主义或虐童（CSAM）内容。文本默认不扫描，除非有人举报。
  • 连坐机制：若群组被认定传播严重违禁内容，该群会被永久封禁，**群主和管理员账号也会被连坐封禁**。但普通成员若未参与传播，通常免责（避免误伤记者或围观者）。
🔤 圈内黑话：UID、DC、Ban、禁言 是什么？ ▼

UID (用户标识)：账号底层的数字ID，无法更改。可用 @getidsbot 查询。重新注册会生成新 UID。

DC (数据中心 Data Centers)：注册时由国家决定。+86 手机多在 DC5(新加坡)，+1 手机多在 DC1(美国迈阿密)。这决定了你下载图片和视频的服务器节点。近两年 DC1 炸得比 DC5 还多。

Ban (封禁/拉黑)：被群管 Ban 代表被踢出群且拉入黑名单，永远无法加入；账号被官方 Ban 则代表死号。

禁言 (Mute)：你还在群里，也能看聊天，但无法发送消息。管理员可设置禁言倒计时。

如何找管理员？消息中带有“管理员”头衔；或者在群里发 @admin 呼出（慎用）；或者点群头像筛选。
